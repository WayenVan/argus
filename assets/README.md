# Argus · Iris

选定标志：Array 模块阵列。三道错位模块代表并行工作的 agents。

## 配色

| 用途 | 色值 |
| --- | --- |
| 左侧模块 · 鸢尾紫 | `#8068F2` |
| 中间模块 · 浅丁香紫 | `#AD99F8` |
| 右侧模块 · 雾蓝 | `#6289ED` |
| 深色背景 | `#151827` |
| 浅色背景上的字标 | `#25263B` |
| 深色背景上的字标 | `#F2F0FA` |

## 文件

- `logo.svg`：透明底完整 Logo，用于浅色背景。
- `logo-on-dark.svg`：透明底完整 Logo，用于深色背景。
- `logo-mark.svg`：彩色独立标志。
- `logo-mark-mono.svg`：单色独立标志。
- `app-icon.svg`：深色圆角应用图标。
- `logo-preview.svg` / `logo-preview.png`：配色与应用预览。

正式 Logo 全部由矢量路径构成，不依赖字体、外部资源、滤镜或渐变。`alternatives/` 保留初始方案，正式使用请采用本目录文件。
